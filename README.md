# To Do App

<p align="center">
  <img src="assets/icon/icona.png" alt="To Do App Logo" width="200" style="border-radius: 30px;"/>
</p>

A modern, minimalist task management application built with Flutter. This app helps users organize their daily tasks with a clean interface and local storage capabilities.

## 🚀 Features

- ✅ **Task Management**: Add, complete, and delete tasks easily
- 💾 **Persistent Storage**: Tasks are saved locally using Hive database
- 🌙 **Dark Theme**: Sleek dark mode interface for comfortable viewing
- 🎯 **Simple Interface**: Clean and intuitive user experience
- 📱 **Responsive Design**: Works smoothly on all screen sizes
- ⚡ **Fast Performance**: Lightweight and efficient

## 🛠️ Technical Details

### Built With
- Flutter 3.x
- Hive Database for local storage
- Material Design 3

### Dependencies
```yaml
dependencies:
  flutter_slidable: ^4.0.0
  hive: ^2.2.3
  hive_flutter: ^1.1.0
```

## 🔧 Installation

### Prerequisites
- Flutter SDK (>=3.7.0)
- Dart SDK
- Android Studio / VS Code

### Building from Source

1. Clone the repository
```bash
https://github.com/SAHILDUDHAL21/To-Do.git
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the app
```bash
flutter run
```

## 📖 Usage

1. **Adding Tasks**
   - Tap the + button to add a new task
   - Enter task details and save

2. **Completing Tasks**
   - Check the checkbox to mark a task as complete
   - Swipe left to delete a task

3. **Managing Tasks**
   - All tasks are automatically saved
   - Tasks persist even after closing the app
